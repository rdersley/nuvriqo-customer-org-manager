# Nuvriqo Customer & Organisation Manager — Support

## How to get help

- **Support portal:** https://nuvriqo.atlassian.net/servicedesk/customer/portal/2
- **Email:** support@nuvriqo.com

## What to include

- Your Atlassian site address (for example `yourcompany.atlassian.net`)
- The app version (shown at the top right of the app and in the footer)
- What you did, what you expected, and what happened, including any message shown in the app
- For import problems: the approximate number of rows, and the import session ID from the Import History tab
- A screenshot if it helps

Please don't send passwords, API tokens, or CSV files containing customer data unless we ask. A few sample rows with the personal details replaced are usually enough.

## Response targets

| Severity | Example | First response |
|---|---|---|
| Critical | The app can't be opened, or imports fail for everyone | 1 business day |
| Major | One feature doesn't work | 2 business days |
| Question | How-to or configuration question | 3 business days |

Business days are Monday to Friday, excluding public holidays.

## Security issues

Email support@nuvriqo.com with "Security" in the subject line. See the security & privacy page for details.
